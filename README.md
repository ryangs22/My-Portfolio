# 🐉 Ryan Gabriel | Personal Portfolio

Seja bem-vindo(a) ao meu portfólio pessoal e interativo, desenvolvido para apresentar minha história, minhas habilidades e trajetória acadêmica, meus projetos que desenvolvi e meus canais de contato. O projeto foi construído do zero utilizando ***HTML5, CSS3 e JavaScript Puro***, focado em performance, design responsivo, animações fluídas e acessibilidade.

🌐 **Acesse o site online:**

---

## ✨ Funcionalidades

- 📱 **Design Totalmente Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- 🎨 **Interface Moderna & Temática Japonesa:** Layout moderno em Dark Mode com detalhes visuais em Japonês (Kanji) e efeitos dinâmicos no cursor.
- 🖼️ **Carrossel Interativo de Projetos:** Galeria de imagens dos projetos com suporte a navegação por clique e gesto de arrastar (*touch/drag*).
- ✉️ **Formulário de Contato Direto:** Integração com **EmailJS** para envio de mensagens diretamente para meu e-mail sem recarregar a página.
- ⚡ **Alta Performance:** Construído sem *frameworks* pesados, garantindo um carregamento ultrarrápido.
